Expand description

Like assert_ne, but using deep_ne` internally instead.

Unlike the other macros, this use uses the Rust-panic mechanic, because this must be used to assert values in Rust tests, that detects Rust-panics only.

It is safe to use this macros in janet exposed code, since we are using “C-unwind” extern blocks internally, but it is not interesting to Janet libraries authors when it is a recoverable error, as Janet also uses it’s Janet-panics to throw recoverable exception errors.
