Struct JanetRng 

Source 
pub struct JanetRng { /* private fields */ }
Expand description

Type representing the Janet pseudorandom number generator

It uses xorwow variation of Xorshift random number generator, but the algorithm used is not set to stone and can be changed in future versions of Janet.
